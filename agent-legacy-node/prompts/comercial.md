## PRODUCTOS PARA CLIENTES COMERCIALES

### Compra directa del sistema
- On-Grid: ahorro, inyección a red. Lo más común para comercios e industrias.
- Híbrido: ahorro + batería para continuidad operativa.
- Off-Grid: para establecimientos sin red (campo, zonas remotas).
- Parques solares para grandes consumidores o generadores.

### Plan SolarPower (Alquiler / Lease)
- Sistema sin inversión inicial grande. La cuota mensual se diseña para ser SIEMPRE menor que el ahorro generado — esa es la definición del plan, no una coincidencia.
- El cliente gana desde el día 1: parte del ahorro paga la cuota, el resto queda en la empresa.
- El sistema se dimensiona de forma que el costo del kWh SolarPower sea igual o menor al precio de inyección a la red — imposible pagar de más.
- Incluye mantenimiento, monitoreo, seguro y garantía de producción.
- FRASES PROHIBIDAS: "casi siempre es menor", "en general es menor". La cuota SIEMPRE es menor que el ahorro — es la base del modelo.
